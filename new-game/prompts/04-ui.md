# UI

```
Build a [SCREEN, e.g. shop] UI in src/client/.
Style: [e.g. chunky cartoon, rounded corners, bright gradients, bouncy tweens].
Requirements: scales on phone + tablet + desktop (UDim2 scale + UIAspectRatioConstraint + UIListLayout),
opens/closes with a tween, gamepad + touch friendly, no hardcoded text (read from Config),
all colours/fonts defined once in src/client/Theme.luau, sizes through src/client/Layout.luau,
opened from a tile in the top-left Menu (MenuUI.AddTile + a line in Config.Menu.Tiles),
registered with PanelManager so only one panel is open at a time and Escape closes it.
```

Tip: for visual concepts first, generate mockups with an image model (see `thumbnails/generate.mjs` in this repo), then ask Claude to rebuild the mockup in Luau.
