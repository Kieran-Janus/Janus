# Prompt library

Paste these into Claude Code (opened in `new-game/`). `CLAUDE.md` already tells Claude the rules, so prompts stay short.

| File | Use it to |
| --- | --- |
| `01-game-design.md` | Turn a vague idea into a one-page design + feature backlog |
| `02-add-system.md` | Add any gameplay system (shop, pets, inventory, quests...) |
| `03-tweak.md` | Make quick balance/content changes safely |
| `04-ui.md` | Generate polished UI |
| `05-ai-npc.md` | Add a new AI-powered NPC or feature |
| `06-review.md` | Security / exploit / performance audit before launch |
| `07-live-ops.md` | Events, updates, retention loops |
