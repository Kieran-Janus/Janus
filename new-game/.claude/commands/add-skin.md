---
description: Add a new crate skin to a theme (it can move and have a walk style too). Usage: /add-skin <theme> <rarity> <what it looks like, and how it should move>
---

Add a crate skin: $ARGUMENTS

1. Read `CLAUDE.md`, `docs/CUSTOMIZE.md` > "Change and animate skins" (Way 2 has an example entry with every setting) and "Crate skins", `src/shared/Config/Skins/init.luau`, `src/shared/Config/Skins/Settings.luau`, the style options at the top of `src/shared/Config/Skins/Pumpkin.luau`, and the theme file you will edit.
2. Pick the theme (one of the 30 in `Themes` in `Skins/Settings.luau`, e.g. `Pumpkin`, `Candy`, `Spooky`, `Graveyard`, `Monster`, `Moonlight`, `VampireCastle`...) and the rarity (`Common`, `Uncommon`, `Rare`, `Crazy`). If I didn't say, choose and tell me why. Follow the rarity look rules: Common = colours, materials and an accent; Uncommon = + a head piece (`src/shared/HeadPieces.luau`); Rare = + `Glow` and an `Aura`; CRAZY = everything + `Crazy = { Rainbow = true, Pulse, Orbit, Count }` and a head piece no other skin uses. Spooky-cute, never gory. A new CRAZY skin changes the CRAZY Crate and the "exactly 10 CRAZY skins" rule: ask me before making one.
3. In the theme file, copy a skin block of the same rarity and paste it at the end of that rarity's group. Give it a new `Id` = `<Theme>_<NameWithoutSpaces>` (search the whole Config folder to be sure it's unique), a `Name` and its `Style`. **Never change an existing `Id`.** Only add `Price`, `CrateOnly` or `Crate` if I asked.
   **Moving pieces and walk styles** (when I ask for them, or when they clearly suit what I described, like a bat's wings): an `Animate` list (Uncommon 1 effect, Rare 3, CRAZY 6, `Config.SkinAnimate.Rarity`) and, for Rare and CRAZY only, a `Motion` walk style. Pick from the tables "Every animation effect" and "Every walk style" in `docs/CUSTOMIZE.md`, check every `Target` exists on the skin (Wings needs the Wings pattern, SparkleBurst an `Aura`), keep `Speed` 0.3 to 2, and end the list with `} :: { any }, -- (effects differ in shape)`. A CRAZY skin can't colour its accents or `Pulse` / `Flicker` its glow (CRAZY owns those). `/animate-skin` has the full rules.
   Real Roblox catalog items (`Catalog`: hats, back items, classic clothes) only if I ask for them. Every id must be made by Roblox, me or my group, and listed in `Config.SkinCatalog.ApprovedIds`: never add an id there yourself unless I say yes and you know who made it (see `docs/CUSTOMIZE.md` > "Catalog items in skins"). Clothes need `HideClothes = false`.
4. If no existing head piece or pattern fits, add a builder in `src/shared/HeadPieces.luau` (or a pattern in `src/shared/Cosmetics.luau`) in the same style, and list it in the style options comment at the top of `Pumpkin.luau`.
5. Tell me how the odds changed: skins of one rarity share that rarity's chance, so adding one lowers the others' chance in that crate and in the rarity crate (`src/shared/CrateOdds.luau`, `CrateOdds.Chances`). A second CRAZY skin in one crate halves each CRAZY skin's chance.
6. The offline tests guard the catalogue on purpose: `tests/specs/skins.spec.luau` wants exact rarity counts per theme (`COUNTS` for the six classic themes: 12 Common, 5 Uncommon, 2 Rare, 1 CRAZY; `NEWER_COUNTS` for the other 24) and the 630-ish total, and `tests/specs/crates.spec.luau` checks the Pumpkin Crate's 20 cards and its 5.833% Common chance and one CRAZY per theme in the CRAZY Crate. Update those rules to the new exact numbers (don't delete the checks) and say so in the commit message. Then run `stylua src`, `selene src` and `lune run tests/run`: all must pass (they also check that no two skins look the same and every `Animate` / `Motion`).
7. Look at it, **only if the preview tooling exists** (the cloud session has `/tmp/claude-0/render/export.luau`; skip this on my PC): `lune run tests/catwalk -- ids <Id>` and render it as the command prints.
8. Playtest in Studio when it is connected: F8 > "+ Coins", Menu > Skins, filter by the theme, buy it, wear it. Look from the front and side, walk and jump (pieces move and stay attached), reset the character, unequip (the avatar comes back). For a CRAZY skin, check the rainbow, orbit and pulse. Open the theme's crate preview: the skin is listed with its chance and the chances add up to 100%. Tell me I can fine-tune its colours and animations by eye in Skin Studio (Menu > Skin Studio, pick the skin, change it with **Wear on me** ticked, Save, then `/save-skins` before Stop).
9. Commit "Add skin: <name>" (only the files you changed, by name) and push to the current branch (never force-push). Tell me the Id, rarity, shop price, which crate it's in and its chance, and what moves.
